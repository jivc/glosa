# Glosa

Programa de escritorio libre y gratuito para el análisis cualitativo de datos (QDA), en español. Sigue el flujo de trabajo de Atlas.ti y funciona sin conexión: los datos se quedan en tu computadora.

**Descarga e instrucciones:** https://juliovega.org/glosa.html

## Funciones

- Importa DOCX, PDF con texto, ODT, RTF, Markdown, HTML y texto plano.
- Codificación con atajo, in vivo, por arrastre y citas libres; códigos visibles en el margen.
- Jerarquías y grupos de códigos, fusión y frecuencias.
- Memos analíticos, metodológicos, teóricos y reflexivos vinculados a citas, códigos o documentos.
- Redes de códigos exportables a PNG, SVG y GraphML.
- Tabla código–documento, co-ocurrencias con coeficiente c, consultas booleanas y nube de palabras.
- Importa y exporta REFI-QDA (.qdpx, .qdc), compatible con Atlas.ti, MAXQDA, NVivo y QualCoder.
- Exporta a Excel, CSV, Word, Markdown y JSON.
